# Doah Play v0.5 — 15장 그림책, 가족 녹음 편집, 자동 퍼즐

갤럭시와 iPad에서 실행하는 광고 없는 오프라인 PWA입니다.

## v0.5에서 실제 변경한 사항
- **15페이지 그림책**: 8장의 오리지널 일러스트레이션을 15개 장면에 맞춰 재구성하고 각 장면별 대사/핫스팟/반응을 정의했습니다. 장면이 나뉘는 페이지는 한 그림의 다른 부분을 이야기하므로 **일러스트 8장을 재사용**합니다. 15장의 서로 다른 새 그림은 아닙니다.
- **가족 음성 편집**: V2 보정본 8개를 조용한 발화 사이 구간을 기준으로 15개 MP3로 분할. 48kHz, 192kbps. 새로 합성하거나 재녹음한 구절은 없습니다. `audio-edit-map.json`에 원본/타임코드가 있습니다.
- **넘김 애니메이션**: 그림 영역 좌우 스와이프 또는 아래 버튼을 누르면 3D 책장 넘김(회전, 그림자) 효과. 접근성 설정에서 동작 줄이기 사용 시 짧은 전환.
- **페이지별 반응**: 돼지·늑대·창문·나무·바람·집 등의 터치 반응을 장면별로 지정. 전환마다 오버레이, 파티클, 말풍선 및 타이머를 정리합니다.
- **오리지널 동물 친구들 퍼즐 5장**: 매 장 8조각, 드래그/탭 맞추기 유지. 완성하면 1.7초 축하 후 다음 그림으로 자동 전환, 마지막에는 완료 화면.
- 기존 낱말 카드, 그림 그리기, 그림책 배경음악 및 부모 설정 유지.

## 설치 / 업데이트
1. ZIP을 압축 해제하고 **폴더 안 모든 파일**을 저장소 최상위에 업로드합니다.
2. `https://github.com/wjdgoeld-hash/doah-play/upload/main` → 파일 선택 → **Commit changes**.
3. GitHub Pages 배포 완료 후 `https://wjdgoeld-hash.github.io/doah-play/?v=05` 접속. 첫 접속은 온라인 상태에서 실행해야 오프라인 파일이 캐시됩니다.
4. 앱 상단에 **v0.5** 표시 확인.

현재 원본 가족 음성은 사용자가 공개 배포를 허용했습니다. 이 저장소에 업로드된 음원 파일은 다른 사용자도 다운로드할 수 있습니다.

주의: 이 버전의 장면별 텍스트는 나레이션 내용을 간추린 **화면용 요약 문장**입니다. 음성은 실제 녹음 파일의 장면 구간을 분할해 재생합니다. 원래 말의 순서를 바꾸거나 새 구절을 합성하지 않았습니다. 음성과 화면 내용의 세밀한 싱크는 실제 기기에서 검증이 필요합니다.
