# Doah Play v0.3 — 도아의 놀이 세상

광고·로그인·외부 데이터 전송 없이, 보호자가 지도하는 유아 놀이 PWA입니다.

## v0.3 업데이트

- **오리지널 피아노 연주곡 메들리**: 그림책 외 모든 화면에서 반복 재생. 모바일 운영체제 정책 때문에 최초 화면을 **터치한 뒤** 재생됩니다. 음악 버튼으로 언제든 끌 수 있습니다. 특정 상업 찬양곡의 원곡을 재연한 음원은 포함하지 않았습니다.
- **뽀로로풍 8조각 그림 퍼즐 3장**: 눈사람·소풍·바다, 포인터 드래그&드롭 및 조각/칸 두 번 누르기. 오답이면 빨간 강조 + 띠리리링 효과음 + 원래 자리로 되돌림. 그림은 생성된 **비공식 이미지**이며 정식 애니메이션 화면 캡처나 공식 제공 아트가 아닙니다.
- **한영 낱말 카드 24개**: 그림을 탭할 때 한국어 단어 → 영어 단어 → 한국어 예문 → 영어 예문으로 순환. 읽는 중 입력 잠금, 좌우 밀기로 카드 이동, 큰 그림. 실제 한국어/영어 음색은 기기에 설치된 TTS 음성에 따라 달라집니다.
- **움직이는 그림책 『아기돼지 삼형제』 8쪽**: 각 페이지 4~5개의 서술/대사 문장, 자동 한국어 음성 읽기, 원곡이 아닌 페이지별 25초 길이 배경 연주곡. 돼지(꿀꿀), 늑대(커지는 연출), 창문(열기), 나무(흔들림/나뭇잎) 상호작용. 페이지는 **자동으로 넘기지 않고**, 아이와 보호자가 약 25초씩 머무른 후 수동으로 넘깁니다.
- 그림 그리기와 부모 설정 기능 유지, PNG 앱 아이콘 및 오프라인 파일 캐시 포함.

## 갤럭시 휴대폰에서 GitHub에 업로드하기 (컴퓨터 불필요)

1. ZIP 파일을 갤럭시 **내 파일**에서 압축 해제합니다.
2. `doah-play-v0.3` 폴더를 엽니다. **폴더 내부 22개 파일**을 확인합니다. (하위 폴더가 없도록 제작했습니다.)
3. https://github.com/wjdgoeld-hash/doah-play/upload/main 으로 접속하여 압축을 풀었던 **22개 파일을 전부** 업로드합니다. `ZIP` 자체를 업로드하지 마세요.
4. 기존 같은 이름의 파일은 **덮어쓰기**합니다. `index.html`, `app.js`, `style.css`, `sw.js`, `README.md`와 함께 MP3/JPG 파일도 저장소 최상위에 있어야 합니다.
5. **Commit changes**를 눌러 저장합니다. 기존 GitHub Pages 설정(main/(root))은 그대로 둡니다.
6. Pages 배포가 끝나면 https://wjdgoeld-hash.github.io/doah-play/ 에서 실행합니다. 최초에는 온라인에서 한 번 접속해 새 오프라인 캐시를 생성합니다.
7. 이전 버전이 보일 경우 페이지를 새로고침하고 홈 화면 앱을 완전히 종료했다가 재실행합니다. 필요하면 브라우저 사이트 데이터/서비스워커 캐시를 초기화합니다.

## 갤럭시 / iPad 설치

- **갤럭시**: Chrome에서 위 주소 → 더보기 → 앱 설치 또는 홈 화면에 추가.
- **iPad**: Safari → 공유 → 홈 화면에 추가 → 웹앱으로 열기.
- **APK**는 아직 제작하지 않았습니다. 이 ZIP은 두 기기에서 작동하는 **설치형 웹앱 PWA 소스**입니다.

## 세부 기술 / 알려진 제약

- HTML, CSS, JavaScript + Service Worker, 외부 라이브러리와 CDN 없음. 총 22개 파일.
- 음악 MP3와 퍼즐 JPG는 브라우저에 캐시됩니다. Safari·Android 미디어의 MP3 Range 요청을 오프라인 캐시가 지원하도록 작성했습니다.
- 브라우저 자동재생 차단 정책 때문에 **첫 터치 이전 소리가 나지 않을 수 있습니다.** 첫 화면을 터치하고 소리 버튼을 확인해 주세요.
- TTS는 기기에 내장된 `speechSynthesis`를 사용합니다. 한국어·영어 목소리, 시작 속도, 오프라인 음성 지원 여부는 기기별로 다릅니다. 화면 읽는 중 카드 잠금에는 TTS 완료 이벤트와 시간 제한을 병행합니다.
- 음악은 자체 제작한 두 개의 새로운 선율을 연결한 부드러운 피아노곡입니다. 요청한 두 찬양의 기존 멜로디/녹음본을 복제한 음원이 아닙니다. 향후 사용 권한이 있는 녹음본을 제공받으면 교체할 수 있습니다.
- 그림책은 민담 『아기돼지 삼형제』를 바탕으로 **독자적으로 집필하고 SVG로 그린** 비공식 각색입니다. 애니메이션은 경량 CSS 기반이므로 반복되는 작은 움직임입니다.
- 부모 수학 문제는 간단한 진입 방지이며 보안 인증은 아닙니다. 사용시간 제한은 앱 내부에서만 동작하며 운영체제 전체 시간을 차단하지 않습니다.
- 다른 웹사이트나 분석 서버에 도아의 데이터, 마이크, 카메라 정보를 보내지 않습니다.
