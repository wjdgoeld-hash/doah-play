# Doah Play v0.4 — 실감나는 아기돼지 삼형제 그림책

이번 버전은 원본 Doah Play v0.3의 기능을 유지하며, **새로 생성한 그림 8장**과 **부모님이 직접 녹음한 8개 나레이션**을 포함합니다.

## 새로운 기능
- 각 페이지마다 고해상도 3:4 그림책 삽화 (WebP로 최적화)
- 그림을 톡톡 누르는 반응: **돼지 인사, 늑대 확대 등장, 바람/집 흔들림, 나무 낙엽, 새 소리, 꽃잎 효과**
- 창문을 터치하면 **양쪽 덧문이 열리고 가구·찻잔·테이블이 보이는 집 안 미니어처 장면** 등장. 다시 누르거나 X로 닫기
- 첫 페이지부터 마지막 페이지까지 **직접 녹음한 MP3가 페이지별 자동 재생**, 기존 페이지 음악은 읽는 동안 자동으로 작은 음량이 되고 끝나면 복귀
- 첫 화면에서 한 번의 사용자 제스처로 음성 및 음악이 재생될 수 있도록 구성
- 기존 그리기·8조각 퍼즐·낱말 카드·시간 제한 유지, 모든 기본 파일 오프라인 캐시 지원

## 개인 음성 공개 배포 안내
**가족 나레이션 8개의 공개 배포를 사용자가 명시적으로 승인했습니다.** 이 ZIP에 포함된 MP3를 공개 GitHub Pages 저장소에 업로드하면 **누구나 음성 파일에 접근하여 다운로드할 수 있습니다.** 공개 배포와 제삼자 접근이 가능하다는 점을 확인하고 업로드하세요.

## 설치 및 배포 (PC 없이 모바일에서)
1. `doah-play-v0.4.zip` 파일을 갤럭시의 내 파일 앱에서 압축 해제합니다.
2. 압축 폴더 안에 있는 **모든 파일을 저장소 최상위(main/root)** 에 업로드합니다: https://github.com/wjdgoeld-hash/doah-play/upload/main
3. 같은 이름의 기존 파일은 덮어쓰고 **Commit changes**를 누릅니다.
4. 배포가 끝나면 https://wjdgoeld-hash.github.io/doah-play/ 에서 상단 **v0.4** 표기를 확인합니다.
5. 한 번 온라인에서 접속해 전체 파일을 캐시하면 기본 기능을 오프라인에서도 사용할 수 있습니다.
6. 오디오 자동재생은 모바일 정책상 앱을 한번 터치해야 시작될 수 있습니다.

## 구현상의 참고
- 이미지 자체는 정지 그림으로, 천천히 이동하는 애니메이션 및 독립된 터치 레이어로 상호작용을 구현합니다.
- 창문 속 집 내부는 **별도로 제작한 SVG 미니어처 장면**입니다. 원본 그림의 실내를 실제로 촬영한 이미지나 동일한 내부 공간과 연결한 3D 장면은 아닙니다.
- 오리지널 삽화는 퍼블릭 도메인 민담에서 출발해 새로 제작했고, 별도 그림책 저작물의 이미지를 복제하지 않았습니다.
- 아직 APK/IPA가 아닌 설치형 PWA입니다.
